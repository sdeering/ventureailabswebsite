- `alpha-ai-labs-logo15.png` - Main AI logo used in header and favicon
- `lightbulb-ideas.png` - Hero section image with lightbulb and tech icons
- `lightbulb-img.png` - Original lightbulb image (backup)

## Favicon Files (in /public/)
- `favicon.ico` - Standard favicon
- `favicon-16x16.png` - 16x16 pixel favicon
- `favicon-32x32.png` - 32x32 pixel favicon

All images are optimized for web use and support both light and dark themes.
